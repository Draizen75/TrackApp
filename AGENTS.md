## Mandatory Regression Prevention

When implementing or modifying any feature:

1. Analyze dependencies and affected existing modules before coding.
2. Preserve existing behavior unless explicitly requested otherwise.
3. Prefer minimal, targeted changes over broad refactors.
4. Add or update regression tests for impacted workflows.
5. Run relevant existing tests, type checks, and builds.
6. Inspect API, database, permission, and data-integrity impacts.
7. Never remove or weaken tests just to obtain a passing result.
8. Never perform destructive database operations without approval.
9. Report confirmed regressions and unresolved risks.
10. Do not declare the task complete until relevant checks have passed or all limitations are explicitly documented.
