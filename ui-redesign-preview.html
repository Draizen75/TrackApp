Review focus

Flow before polish

Use the bottom navigation to review each page. The mock uses sample transactions so the hierarchy can be judged in a populated state.

  • Is the key action easy to spot?
  • Are balances and fees easy to scan?
  • Does the color feel comfortable and trustworthy?
Proposed redesign plan
  1. Agree on a color and typography direction.
  2. Finalize dashboard and quick-entry hierarchy.
  3. Apply shared components and spacing across all five pages.
  4. Check empty, populated, loading, error, and small-screen states.
  5. Validate with app tests and platform screenshots.
Not production UI

No app source files or data are changed by this preview. The selected theme is for discussion and does not persist after reload.
